# Ромчик красавчик — версия на C++ (Windows .exe)

Полный перенос игры из `romchik.html` на C++17: все комнаты, рыбалка, бар и компания, мини-игры
(тир, лови еду, овцы, красотки, шашлык, туалет, стрижка, Надюха, аркада, дурак, знакомства, погоня),
голос Ромчика с липсинком, запись микрофона, мутант, сохранение прогресса.
Картинки и звуки упакованы в `assets/assets.bin` и вшиваются в exe — получается один файл `Romchik.exe` (~12 МБ).
Внешних библиотек нет: окно Win32 + Direct2D/DirectWrite + winmm (Windows 8.1 / 10 / 11).

## Как получить exe

**Вариант 1 — без установки компилятора (GitHub Actions).** Загрузите папку в репозиторий GitHub →
вкладка Actions → build-exe → скачайте артефакт `Romchik-exe`.

**Вариант 2 — Visual Studio.** Откройте «x64 Native Tools Command Prompt», перейдите в папку и выполните `build_msvc.bat`.

**Вариант 3 — MinGW-w64** (MSYS2, w64devkit, WinLibs): `build_mingw.bat`.

## Управление
Мышь/тач как в оригинале. Рыбалка: Пробел — подсечь/держать. Погоня: ← →.
Сохранение: `%APPDATA%\Romchik\save.txt`.

## Структура
- `src/game.cpp` — состояние, комнаты, персонаж, панель, бар/компания, ввод
- `src/fishing.cpp` — рыбалка · `src/overlay.cpp` — мини-игры
- `src/mixer.cpp`, `src/assets.cpp` — звук и ресурсы (портативные)
- `src/win_main.cpp` — Windows-бэкенд
- `dev/` — тестовый Linux-бэкенд (дымовой тест и рендер кадров в PNG)
